# Verilay Roadmap

## Shipped

- GitHub URL analysis, ZIP upload, live URL scan
- Expert mode and Learner mode (plain-English explanations, analogies)
- Architecture diagram + plain-English breakdown of what each part does
- Secret scanning — every file checked directly for exposed keys and passwords
- Dependency vulnerability checking against OSV.dev
- Ask Verilay, grounded in your own report's actual findings
- Saved, shareable reports
- GitHub score badge for your README
- Analysis history (local)
- Deep scan (paid, one-time) — reads far more of your codebase, exact package names and fixes for every dependency vulnerability, unlimited re-scans of the same app for 30 days
- Passwordless email sign-in for deep scan purchasers

## What's next

Nothing here is scheduled — these are real ideas, built when there's a
concrete reason to build them rather than speculatively.

- Re-scan comparison — show what changed since your last scan of the same
  app, instead of a fresh report every time
- Continuous monitoring — the same weekly re-scan + diff Verilay already
  runs on its own apps, available for yours
- GitHub App — webhook-triggered scans and PR comments instead of pasting
  a URL each time
- Smarter dependency version detection for projects that don't pin exact
  versions
- Browser extension — a Verilay panel inside Lovable and Replit
- Email report delivery

Found something you'd like to see here? Open an issue.
